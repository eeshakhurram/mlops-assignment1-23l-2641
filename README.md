# mlops-assignment1-23l-2641

# Setup Instructions

1. Clone this repository:
   git clone https://github.com/eeshakhurram/mlops-assignment1-23l-2641.git
   cd mlops-assignment1-23l-2641

2. Create and activate a virtual environment:
   python -m venv venv
   venv\Scripts\activate      (Windows)

3. Install dependencies:
   pip install -r requirements.txt

4. Add your dataset as data/dataset.csv

5. Run training:
   python src/train_l232641.py

The trained model will be saved to the model/ directory.
